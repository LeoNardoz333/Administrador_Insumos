# Administrador_Insumos
Aplicación de escritorio para la administración de costes e insumos para pequeños locales de comida.
- Registro de los insumos del local.
- Cálculo de costos, ventas y ganancias.

Tecnologías utilizadas:
- C#
- Base de datos MYSQL

Entornos de desarrollo:
- Visual Studio
- Laragon
